# Новый сектор для ORBIT RUSH

## Шаги
1. Спроси, какой сектор нужен, если это не сказано: метеоритный дождь, кометы, чёрная дыра, пояс кристаллов или своё.
2. Создай модель в `src/world.js` отдельной функцией `makeИмя()`, как `makeAsteroid()`.
3. Добавь появление в `spawn()` в `src/main.js` с условием по номеру сектора, например `if (sector >= 3)`.
4. Новые числа вынеси в блок НАСТРОЙКИ.
5. Цвета только из палитры игры: неон `0x3DF5FF`, розовый `0xFF4FD8`, золото `0xFFC93C`, камень `0x6B5A7E`.
6. Проверь консоль на ошибки и запусти субагента `tester`.

## Стиль
- Низкополигональные фигуры с `flatShading: true`.
- Светятся только важные для игрока объекты (`emissive`).
- Новое препятствие должно быть видно издалека и честно: игрок успевает увернуться.

## В конце
Напиши, с какого сектора появляется новинка и какие файлы изменены.
