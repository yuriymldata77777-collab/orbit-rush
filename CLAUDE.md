# CLAUDE.md: правила проекта ORBIT RUSH

## О проекте
3D-игра в браузере на Three.js. Описание и требования лежат в `spec.md`, читай его перед любой новой функцией.

## Структура
- `index.html` сайт игры (лендинг)
- `play.html` сама игра
- `style.css` общие стили и цвета
- `src/main.js` игровой цикл, управление, счёт
- `src/ship.js` 3D-модель корабля
- `src/world.js` звёзды, астероиды, кристаллы
- Three.js подключается по ссылке с CDN в `play.html` (importmap), версия 0.170.0

## Правила кода
- Только чистый JavaScript с модулями (`import`), без сборщиков и фреймворков.
- Числа, которые влияют на игру (скорость, жизни, время), держать в блоке НАСТРОЙКИ в начале `src/main.js`.
- Комментарии на русском, коротко.
- Цвета брать из переменных в `style.css` (`--neon`, `--hot`, `--gold`).
- Новую механику добавлять отдельной функцией, а не дописывать в игровой цикл.

## Перед тем как сказать «готово»
1. Проверь, что в консоли нет ошибок.
2. Проверь пункты «Готово, когда» из `spec.md`.
3. Коротко напиши, какие файлы изменил и зачем.

## Нельзя
- Добавлять ключи, пароли и токены в код.
- Удалять файлы без вопроса.
- Менять версию Three.js без вопроса.
